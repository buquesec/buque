# 已实现功能清单

> 产品：**补阙漏洞管理系统** 0.1.4。宣传语：**漏洞有账，处置有单。**  
> 更新日期：2026-11-02。  
> 安装后打开 http://127.0.0.1:8080 。全新安装只有账号、角色、菜单和默认配置，没有示例组织、项目和漏洞。

登录不需要授权文件。菜单按角色权限显示，下面是平台管理员能看到的完整菜单。

默认进入顶栏 **漏洞态势**。没有该权限时，进入工作台的「我的待办」。

使用说明见 [产品使用说明书](./user-guide.md)。

---

## 顶栏

| 模块 | 说明 |
|------|------|
| 漏洞态势 | 数据范围内的风险概览与趋势，点指标进入列表 |
| 工作台 | 待办与站内消息 |
| 漏洞中心 | 漏洞数据、扫描发现、报告 |
| 资产库 | 项目、应用系统、系统模块、仓库地址 |
| 系统管理 | 组织权限、平台配置、检测接入、流程、审计 |

不在侧栏、从页面进入的：漏洞详情、录入漏洞、发起检测任务、工单详情、漏洞画像。

## 漏洞态势

| 菜单 | 路径 | 做什么 |
|------|------|--------|
| 漏洞态势 | `/workbench/posture` | 六个指标、应用系统待跟踪排行、存量/新增/关闭、高危名称排行和趋势。点数字或柱形下钻，折线图只看趋势 |

## 工作台

| 菜单 | 路径 | 做什么 |
|------|------|--------|
| 我的待办 | `/work-orders/todos` | 我的待办、我参与的、我创建的；管理员还可看全部进行中工单 |
| 消息 | `/notifications` | 站内信。白名单临近到期时收到「白名单即将到期」 |

工单详情 `/work-orders/:id`：一张工单对应多条漏洞，可办子项、传附件、按流程推进。

## 漏洞中心

### 漏洞数据

| 菜单 | 路径 | 做什么 |
|------|------|--------|
| 漏洞列表 | `/vulnerabilities` | 筛选含处置优先级（P0–P3 / 未计算）、基线、白名单、监管、资产、工具、标签、更新时间。工具栏收成「操作」：录入、导入、批量发起、批量处置、加入基线、生成报告、计算优先级 |
| 漏洞基线 | `/vulnerabilities/baseline` | 纳入基线的漏洞不再进入日常待办，扫描记录仍保留 |
| 漏洞白名单 | `/vulnerabilities/whitelist` | 加白规则。生效规则可改到期时间和原因。临近到期会加分并回到待办 |
| 监管漏洞 | `/vulnerabilities/regulatory` | 独立台账。可手工新建、Excel 导入、通报提取。按 CVE、厂商编号、CNVD、CNNVD、组件和版本范围关联资产漏洞 |

录入漏洞 `/vulnerabilities/entry`：单条或 Excel 导入。  
漏洞详情 `/vulnerabilities/:id`：字段、处置、工单、基线、白名单、监管和标签。右上角显示处置优先级，悬停可看得分并重算本条。

### 扫描发现

| 菜单 | 路径 | 做什么 |
|------|------|--------|
| 任务列表 | `/discovery/tasks` | 发起和查看检测任务。SonarQube 按关联仓库扫描；Dependency-Track 按系统模块和模块版本上传物料清单（CycloneDX、带版本的 pom.xml、SPDX JSON）后拉取组件漏洞。详情含入库统计、门禁、待跟踪、基线、白名单、监管命中、本次发现和同步作业 |
| 扫描对比 | `/discovery/compare` | 按同步作业或任务全量对比两次结果 |
| 任务门禁 | `/discovery/gate` | 多条门禁策略。任务结束后按命中范围判定通过或不通过 |

发起检测任务从任务列表进入。

### 报告中心

| 菜单 | 路径 | 做什么 |
|------|------|--------|
| 报告列表 | `/vulnerabilities/reports` | 漏洞报告、扫描报告、监管报告和整改清单的生成与下载 |

## 资产库

| 菜单 | 路径 | 做什么 |
|------|------|--------|
| 项目资产 | `/assets/projects` | 项目维护，可进该范围的漏洞画像 |
| 应用系统 | `/assets/app-systems` | 应用系统维护，含版本、仓库和画像 |
| 系统模块 | `/assets/app-subsystems` | 挂在应用系统下的模块，含版本、仓库和画像 |
| 仓库地址管理 | `/assets/repos` | 集中维护 Git / SVN。管理员可查全部并 Excel 导入；负责人和模块负责人在行内维护自己的仓库 |

漏洞画像从项目、应用系统或系统模块的行内进入，看概览、趋势和待处置。

## 系统管理

### 组织权限

| 菜单 | 路径 | 做什么 |
|------|------|--------|
| 组织架构 | `/system/org` | 部门树 |
| 人员维护 | `/system/users` | 用户、部门、角色、启停、重置密码 |
| 角色权限 | `/system/roles` | 菜单、按钮权限和数据范围 |
| 账号与改密 | `/system/account` | 当前用户改密。页面标题为「账号与密码」 |

### 平台配置

| 菜单 | 路径 | 做什么 |
|------|------|--------|
| 系统信息配置 | `/system/config` | 产品名称、版本、简介、Logo。授权文件可导入，不作为登录条件 |
| 大模型配置 | `/system/ai-config` | 接口与提示词。接通后才出现 AI 解读和通报提取，写入前须人工确认 |
| 漏洞信息配置 | `/system/vuln-config` | 五个页签：漏洞类型及扫描工具映射、监管漏洞自动关联、漏洞防重复、自动关闭、处置优先级（权重、等级线、计算时间，EPSS 与在野利用可填网址或上传文件） |
| 漏洞字段目录 | `/system/field-catalog` | 扩展字段和核心字段说明 |
| 漏洞标签 | `/system/vuln-tags` | 自定义标记。可改颜色、停用；仍被漏洞使用的不能删除。列表可按标签筛选 |
| 密码策略管理 | `/system/password-policy` | 密码复杂度、空闲超时、更换周期 |
| 消息通知 | `/system/notifications` | 站内信事件和文案。白名单到期提醒可设提前天数、提醒次数，以及通知负责人、管理员或规则创建人 |

### 检测接入

| 菜单 | 路径 | 做什么 |
|------|------|--------|
| 工具实例 | `/discovery/tools` | SonarQube 配置地址、Token 和 Scanner；Dependency-Track 配置地址和 API Key，按「模块名称（模块编码）」加模块版本同步 |
| 清洗映射配置 | `/discovery/cleansing` | 把工具字段映射到平台字段 |

### 流程与审计

| 菜单 | 路径 | 做什么 |
|------|------|--------|
| 流程管理 | `/system/workflows` | 流程草稿、阶段、流转、发布版本，以及按工具类型和部门绑定 |
| 日志管理 | `/system/logs` | 登录和配置变更等操作记录 |
