# 补阙

公开仓：https://gitee.com/sea-vessels/main

**补阙**是漏洞管理平台，把扫描、录入、监管通报汇成一本账，按工单走完处置。完整功能请下载 **发行版安装包**（Docker 起库和应用），不要指望从本仓库 `mvn package`。

本仓库只公开**部分源码**（许可证、说明书、扫描工具 Adapter 接口等）。源码公开、禁止转售，**不是** OSI 开源。见 [LICENSE](./LICENSE)（Apache-2.0 + Commons Clause）。

## 主要能力（安装包）

- **仓库与列表**：应用系统、系统模块可维护多条 Git / SVN。发起检测时自动带出仓库；漏洞列表直接显示应用系统、模块、扫描地址、分支和所属项目。
- **漏洞态势**：数据范围内汇总待跟踪、高危未关闭、监管未闭环等指标与趋势，点指标下钻列表，不展示具体漏洞行。
- **完整处置流程**：发现入库后发起整改，工单流转、审批、转派，待办与站内信闭环。
- **存量漏洞治理**：历史扫描、手工/Excel 录入、监管通报提取均可进同一漏洞库，按资产范围持续跟踪。
- **监管与白名单**：独立监管台账（自动/手工关联资产漏洞）；加白规则命中后可从门禁与待跟踪中排除。临近到期会回到待办并提高处置优先级，到期前提醒负责人和管理员。
- **处置优先级**：按漏洞本身、暴露面、等保、监管命中和利用概率计分，分为 P0–P3。可配置权重和计算时间；服务器不能上网时上传 EPSS 与在野利用清单。
- **去重与自动关闭**：同模块同版本按规则全字段去重、关闭后复现可重开；任务中不再出现的漏洞可按规则自动关闭。
- **AI 研判**：大模型解读漏洞影响与处置建议、监管通报提取多条草稿；**写入须人工确认**，不会直接改权威数据。

另有扫描任务、任务门禁、扫描对比、基线、画像与报告等，详见 [使用说明书](./docs/user-guide.md) 与 [已实现功能清单](./docs/implemented-features.md)。

## 使用完整产品

1. 打开仓库「发行版」，下载 `buque-<版本>.zip` 并解压
2. 安装 [Docker](https://docs.docker.com/get-docker/)（不必装 JDK / Node）
3. 执行 `start.ps1`（Windows）或 `./start.sh`（Linux/macOS）
4. 浏览器打开 http://127.0.0.1:8080

首次会构建应用镜像并启动 PostgreSQL，等健康检查通过后再登录。演示账号见安装包内 `README.txt`。仅供本地试用，生产必须改密。
